DANFER INDUSTRIAL OS 1.3.0 - VERSAO WEB LOCAL

1. Extraia todo o conteudo deste ZIP para uma pasta.
2. Execute "INICIAR_WEB.bat".
3. Aguarde alguns segundos; o sistema abrira no navegador.
4. Para encerrar, feche a janela do servidor.

Endereco local: http://127.0.0.1:8000
Documentacao API: http://127.0.0.1:8000/docs

Os dados da Biblioteca Tecnica ficam na pasta "data", criada ao lado do
executavel. O Windows pode exibir um alerta por se tratar de um executavel
novo e ainda nao assinado digitalmente.
